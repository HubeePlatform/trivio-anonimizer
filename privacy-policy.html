Política de Privacidade

Extensão: Anonimizador  ·  Última atualização: junho de 2025

1. Sobre esta extensão

O Anonimizador é uma extensão para o Google Chrome que permite ocultar dados sensíveis em páginas web por meio de efeito de desfoque (blur), facilitando gravações de tela e apresentações sem expor informações confidenciais.

2. Dados coletados

Esta extensão não coleta, não armazena em servidores externos e não transmite nenhum dado pessoal. As únicas informações salvas são:

  • A lista de seletores CSS configurados pelo usuário (elementos a serem ocultados).
  • O estado de ativação da extensão (ligado/desligado).

Esses dados são armazenados exclusivamente no próprio dispositivo do usuário por meio da API chrome.storage.local do navegador e nunca saem do dispositivo.

3. Permissões utilizadas

  • storage — para salvar localmente as configurações do usuário entre sessões.
  • tabs — para comunicação interna entre o popup da extensão e o script em execução na página ativa. Nenhum dado das abas é lido ou registrado.
  • host_permissions (<all_urls>) — para injetar o script de ocultação em qualquer site. Nenhum conteúdo das páginas visitadas é lido, copiado ou transmitido.

4. Compartilhamento de dados

Nenhum dado é compartilhado com terceiros. A extensão não utiliza serviços de análise, rastreamento, publicidade ou qualquer API externa.

5. Código remoto

A extensão não carrega nem executa código remoto. Todo o código está empacotado localmente no arquivo da extensão instalada no navegador do usuário.

6. Crianças

Esta extensão não é direcionada a menores de 13 anos e não coleta intencionalmente informações de crianças.

7. Alterações nesta política

Eventuais atualizações serão publicadas nesta mesma página. O uso continuado da extensão após alterações implica aceitação da política atualizada.

8. Contato

Esta política aplica-se exclusivamente à extensão Anonimizador publicada na Chrome Web Store.
